# B.7B review guide

Open [B.7B](../../finishedmockups/Mockup%20B.7B/index.html). It is a small continuation of B.7; the Phone preview remains the default.

1. The Straight Party Ticket heading has no sample opinion or details. Both header icons are faded. Selecting a party does not fill the header with that party's content.
2. Mark Example Group A. The personal oval has an outline, a clear gap, and a filled center. Its recommendation arrow and label remain visible. Clear it to see the original animated hint again.
3. Turn Only Recommended off. Its label becomes Showing All in both views. Example Group D has no opinion or details. Example Group B has a separate nonrecommended opinion.
4. Open Ballot Viewer. It starts zoomed out with Snap off and no green selection outline.
5. Enable Snap, tap a section, or use Next/Prev. The selected section fits the viewer width and gains the green outline.
6. Uncheck Snap. The view stays where it is. Press the floating All icon at the lower right to fit the current page and turn Snap off.
7. Close and reopen the viewer. It starts zoomed out again. The existing B.7 sample still has two pages; section navigation changes page automatically.
8. Use Admin to add or remove an item's own note, then save it. Its content controls update. Personal choices remain separate from editor data.

Back to Start is hidden for this iteration. B.8 is labeled Outmoded Mockup in the gallery and preview header. The local launcher follows B.7B, B.7C, B.7D, and later lettered copies of this line.
