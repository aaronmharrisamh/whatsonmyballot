# B.7E review guide

Open [B.7E](../../finishedmockups/Mockup%20B.7E/index.html). This copies B.7D and makes small changes to My Guide. Phone preview and readable practice ballot sections remain the defaults.

1. Open My Guide before marking any practice choices. It already shows the admin's THIS and OR recommendations in the existing ballot-group containers.
2. Read each recommendation's opinion directly below it. The explanation toggle and Back to sections button are gone. Unmarked choices and races are omitted to keep the cheatsheet compact.
3. On a phone, use the pinned section capsules to jump between the groups. Their widths reflect the rendered group lengths, and their backgrounds fill as you scroll. The current group is indicated.
4. On desktop, Partisan and Non-Partisan keep their side-by-side containers. There is no pinned jump bar.
5. Make different practice choices in Ballot and return to My Guide. The admin's cheatsheet stays the same. Local Admin edits to recommendations and opinions still update it.
6. The original sample PDF and Print controls remain. Ballot Viewer retains B.7D's nearest-center Snap and two-sheet view.

The sample contains Partisan and Non-Partisan groups. Other groups, such as Proposals, appear when their ballot data includes recommendations. B.8 remains outmoded and was not used for this change.
