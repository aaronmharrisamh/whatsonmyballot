# B.7C review guide

Open [B.7C](../../finishedmockups/Mockup%20B.7C/index.html). This is a small continuation of B.7B. Phone preview and the readable section view remain the defaults.

1. Mark a recommended choice. Its oval has an outline, a white gap, and a filled center in the row's guide color. The recommendation arrow or OR label remains visible.
2. Open a section's header opinion. It sits below the header buttons, inside the same header area. An Admin can highlight this opinion without recommending a ballot choice.
3. A highlighted header opinion opens by default. Its opinion button and notice use the selected color. The title and magnifier keep their normal appearance.
4. Use the top Only Recommended / Showing All switch to reveal other choices. The extra section checkbox and upper Back chip are absent. The bottom navigation and Next chip remain.
5. Open Ballot Viewer. Front and Back appear beside each other as separate white sheets, with titles and equal heights.
6. Enable Snap, tap a section, or use Next/Prev. The camera fits that section, including when moving to the other sheet.
7. Press All to fit both sheets and turn Snap off. Unchecking Snap alone keeps the current camera position.
8. Use Admin to edit a header opinion and its highlight, then save and reload. Personal choices remain separate from Admin content.

Empty opinion/detail controls remain faded and disabled. Back to Start is still hidden. B.8 remains an Outmoded Mockup; the launcher follows B.7C and later lettered copies.
