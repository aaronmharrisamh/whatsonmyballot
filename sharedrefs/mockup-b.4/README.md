# B.4 / v0.1.5 review guide

Open [Mockup B.4](../../finishedmockups/Mockup%20B.4/index.html). Phone preview is the default; use Desktop to compare.

## Try the main section

- The heading identifies the precinct. Back and Next move through all 28 sections.
- The progress segments use the relative size of each section. A pulsing segment marks your place. A check means the section has at least one saved choice, even if fewer than the allowed number.
- Fill a circle to make your own choice. The footer has one count and Clear Section.
- Opinion expands in the ballot row. The magnifying glass opens more information. Neither moves an already comfortable view.
- Show guide marks starts on. Turning it off hides guide symbols, colored rows, and automatic opinions. Opinion buttons still work. This reader preference saves separately.

## Compare THIS and OR

Open Admin and expand **See THIS and OR with fictional names**. This separate layout example shows Jim Johnson with THIS and five fictional OR choices. The example never writes to a personal ballot.

Turn on Edit buttons, return to a section, and choose Edit guide mark. Each option has None, THIS, or OR and one of six colors: blue, green, red, yellow, orange, or gray. You can add many THIS and OR marks without grouping them. Marks never fill or constrain the visitor's own choices.

Marked options show a faint check or OR symbol and an inline author opinion. A reader can collapse the opinion. The notes editor lets an admin enter the author's words and source link. Existing saved notes remain in use.

The historical sample starts with no guide marks on real candidates. The fictional examples demonstrate the layout; they are not party endorsements.

## Explore Ballot View

Tap the larger map beside Back. The inset viewer dims the surrounding page.

- Extents shows the current source page.
- Prev and Next select the next section, including sections on the other page.
- Section starts unchecked: navigation fits the section to 75% of the canvas width.
- Check Section for a full-width fit. Tall sections extend below the canvas.
- Use the right-hand slider, pinch gesture, mouse wheel with Ctrl, or keyboard to zoom. Drag, scroll, or arrow keys move the page.
- Lime controls and the green focus frame identify the selected section. Other sections hide their controls.
- X returns to the selected readable section. If the selection did not change, the previous scroll position returns.
- Information and editing dialogs open above the viewer; Escape closes only the top window.

## Local editing

Save, Cancel, Restore original, and a dirty-draft guard apply to guide mark editing. Restore fills the draft; Save commits it. A failed save keeps the draft. A second tab cannot silently overwrite a newer saved revision. Unsaved guide marks have a separate recovery copy.

The Admin JSON import shows the proposed changes before applying them. Exports contain guide annotations only. Personal choices, ballot content, and opinion notes each keep separate storage. See the [annotation contract](ANNOTATIONS.md).
