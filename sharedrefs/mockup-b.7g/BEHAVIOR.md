# B.7G behavior and data

App version 0.2.6; isolated dataset b7g-fictional-ballot-demo; area catalog b7g-sample-areas. B.7G directly copies B.7F. Ballot, notes, annotations, and area schemas are unchanged. B.8 supplied no code or reference.

My Guide projects only saved Admin THIS/OR recommendations and their own opinions. Practice choices, private write-ins, recommendation filters, and viewer positions cannot change it. Its icons now pair the recommendation arrow with a filled oval; Optional uses white OR text inside a filled oval.

Every main app page has a fixed, short page label directly below the app header. Phone My Guide category navigation follows that label. Category progress remains measured and jumps remain immediate. Desktop keeps the page label and two guide columns without phone category tabs.

The recommendation PDF keeps Front and Back on two Letter pages with 11.5-point names and titles, adds darker main section bands, and uses a compact visual hierarchy. It draws from saved author data, not the current camera or personal marks. County and Township context stays with repeated office titles. Full opinions belong to Print my Guide. Saved edits too large for a readable two-page Letter or Legal PDF produce an actionable error rather than clipping; unsupported font characters use the existing Print alternative. All PDF assets remain local and pinned.

Print my Guide gives each major category a distinct rounded container and keeps its own two-column content flow. Dark category headers repeat on continuation pages, so the category stays clear when a container spans more than one printed page. The sample produces five Letter pages with 12-point opinion text and 12.5-point choice names. It includes complete recommendation opinions and source links. Local browser and printer settings can affect pagination. Download success leaves no persistent ready paragraph at either end of My Guide; preparation and failure messages remain available.

Ballot Viewer places Back and Next navigation at the ends of each source column rather than at every race. The sample has five populated source columns and nine boundary controls; the empty sixth column adds no navigation. The boundary controls remain present as the selection changes, including outside Snap. Snap still fits a selected race and preserves the existing two-sheet gestures and section-end recovery. Zoom tools retain the white treatment and navigation stays dark.

Earlier local Admin editing, dirty-draft guards, shared recommendation filtering, and unavailable-area behavior remain. The inherited floating zoom/All controls can cover underlying detail buttons at some pan positions; panning reveals them.
