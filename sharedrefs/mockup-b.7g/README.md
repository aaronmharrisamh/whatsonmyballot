# B.7G review guide

Open [B.7G](../../finishedmockups/Mockup%20B.7G/index.html). This copies B.7F and refines recommendation marks, printable outputs, page labels, and Ballot Viewer column navigation.

1. Move between District, Ballot, and My Guide. A fixed row below the app header names the current page. On phones, My Guide category tabs sit directly below it and still jump immediately.
2. Read the admin’s recommendations. A down arrow points at a filled oval for Recommended; Optional uses white OR text inside the filled oval. These guide marks stay separate from your practice choices.
3. Download **Ballot with Recommendations (PDF)** for Front and Back on two pages with darker section bands and clean recommendation cards. Successful downloads do not leave a repeated ready notice.
4. Use **Print my Guide** for the full opinions, grouped inside distinct Partisan, Nonpartisan, or other category containers with two columns per group. Both output buttons remain at the top and bottom.
5. In Ballot Viewer, find persistent Back and Next buttons at column boundaries. Snap follows sections while the column-end controls let you continue through the ballot.

The example is fictional. B.7G uses isolated saves. B.8 remains outmoded and supplied no code or reference for this work.
