# B.7H review guide

Open [B.7H](../../finishedmockups/Mockup%20B.7H/index.html). This directly copies B.7G and refines page labels, printed outputs, and Ballot Viewer gestures.

1. Move between District, Ballot, and My Guide. A larger centered label with its matching dashboard icon stays below the app header.
2. Use **Print my Guide** for a compact readable guide. Major categories retain their distinct capsules and two-column content. The sample now uses four Letter pages instead of five, with 10.5-point opinions and 11.5-point choice names.
3. Download **Ballot with Recommendations (PDF)** to read recommendation opinions with the ballot visualization. Front and Back remain clearly labeled; full opinions use continuation pages. The sample has six Letter pages: four for Front and two for Back.
4. Zoom with the wheel when Snap is off, or use a pinch gesture. Enable Snap and scroll beyond the top of a column to see the view return to readable ballot content.
5. Phone category tabs still jump immediately. The bottom and top output buttons have the same behavior.

The example is fictional. B.7H keeps isolated saves. B.8 supplied no code or reference.
