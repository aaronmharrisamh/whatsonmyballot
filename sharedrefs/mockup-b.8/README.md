# Mockup B.8 — v0.2.0

**All four parts are complete.** B.8 imports complete JSON collections, edits named guides locally, and exports a portable collection. Its reader and Snap viewer share the same ballot data. My guide, printed guides, and generated ballot PDFs show the selected author's recommendations.
