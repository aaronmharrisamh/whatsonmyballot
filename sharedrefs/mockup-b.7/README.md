# B.7 review guide

Open [B.7](../../finishedmockups/Mockup%20B.7/index.html). Phone view is the default. Use the footer to switch to Desktop.

1. Look at the arrow over the empty oval and the RECOMMENDED label. Mark it: the oval becomes solid.
2. Find the OR option. It has an OPTIONAL label and its opinion is open.
3. Check Show all choices. Some rows have faded opinion buttons with no note. Example Group B has a scale with an asterisk and an Opinion — Not recommended note.
4. Use Next and Back. Show all choices resets. Both nearby-section buttons show the destination count. Back to Start returns to section 1 without clearing choices.
5. Open Ballot Viewer. Its Only Recommendations switch matches the readable view. The wheel zooms with Snap off and scrolls with Snap on.
6. Try the slider, pinch, and Zoom. The farthest view fits the current page with padding; the nearest fits the selected section's width.
7. Go to the final section. It has no sample recommendations; use Show all choices to see its options.
8. Open Menu > Admin to edit a guide mark or note. Save, Cancel, Restore original, and unsaved-draft recovery remain available.

All names, guide marks, and opinions are fictional layout examples. The original two-page PDF remains a historical layout reference. See [behavior and data](BEHAVIOR.md) and [verification](VERIFICATION.md).
