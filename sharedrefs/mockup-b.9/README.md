# B.9 review guide

Open [B.9](../../finishedmockups/Mockup%20B.9/index.html). This directly copies B.7H and adds portable ballot data while keeping its interface.

1. The default example keeps 28 contests and 52 guide recommendations. Practice choices start empty.
2. Open the menu, then Admin. Download **SCHEMAEXAMPLE.json** for a complete format example.
3. Import it. Named pages, explicit columns, contests, proposals, opinions, and attached resources appear in the existing views.
4. Refresh. The imported ballot remains active in this browser.
5. Edit and save author text or recommendations, then **Export ballot JSON**. It includes saved author content and embedded files; practice marks remain separate.
6. Generate My Guide outputs. PDFs support named source pages, full opinions, source titles, and continuation pages.

The default example is fictional. B.8 supplied no code or reference. Read the [behavior](BEHAVIOR.md), [contract](CONTRACT.md), and [verification](VERIFICATION.md).
