# What's on My Ballot?

A static ballot guide prototype with A1–A5, the B mockups, and B.9A as the current available mockup.

**B.9A / v0.3.19 is the current available mockup.** It retains its ballot behavior and adds designer credits in the footer and menu. [Open B.9A](finishedmockups/Mockup%20B.9A/index.html) or read the [review guide](sharedrefs/mockup-b.9a/README.md). B.9B through B.9J are temporarily unavailable; the gallery keeps their labels without launch links or preview files. B.8 remains outmoded.

From the repository root, run:

```powershell
node preview.mjs
```

Open [the mockups](http://127.0.0.1:4173/finishedmockups/). Node is only needed for local preview; no package installation is required. The root entry also works under a GitHub Pages repository path.

[version.js](version.js) is the single app-version source, currently `0.3.19`. It supplies the landing page, preview footer, design notes, Help, and Admin. App versions are separate from the content schema and saved-content revisions.

B.5, B.6, B.7, B.7B, B.7C, B.7D, B.7E, B.7F, B.7G, and B.7H use isolated fictional datasets with neutral filler and random sample marks. The earlier historical sample is **Akron Township, Precinct 1AF, November 5, 2024**. Lake Orion remains the preferred later replacement. Candidate profiles are labeled examples. The [two-page sample PDF](sharedrefs/ballots/2024-11-05-akron-1af.pdf) and [client review guide](sharedrefs/mockup-a/REVIEW.md) are included.

The app and demo documents live in tracked [sharedrefs](sharedrefs/README.md). Research and full county PDFs stay in ignored `/docs/`; development scripts stay in ignored `/tools/`. Withheld mockups, later review files, and example JSONs are preserved in ignored `/unreleasedmockups/`, mirroring their original paths. `.claude/`, root `AGENTS.md`, and root `CLAUDE.md` are also ignored. A fresh clone does not include those local files. The preview helper only serves the public app folders and root runtime files.

Preview and deploy the public files directly from this repository. Keep `sharedrefs/`, `finishedmockups/`, `version.js`, and the root entry files together when using GitHub Pages. No build, release ZIP, or extracted copy is needed. Ignored research, development tools, and withheld mockups stay local.

The public cutoff is B.9A. The launcher honors the available mockup in `finishedmockups/mockups.json`; later IDs are explicitly unavailable. A fresh clone contains only available versions and their supporting files. Moving the withheld files removes their current published paths after a commit, push, and Pages redeploy. Existing Git history is retained for now; `addendum.ini` records the later cleanup.
