# Mockup B1

Open [B1](index.html) through the root HTTP preview. Run `node preview.mjs` from the repository root.

B1 opens on the virtual ballot. Use the zoom controls, pinch, or drag to explore. Choose **One section** for the same ballot content at normal reading size. Chevrons expand short notes; magnifying glasses open full reading dialogs.

Read the [B1 review guide](../../sharedrefs/mockup-b/README.md). Keep the public project layout together. B1 uses the shared ballot data, model, validation, and content-storage modules in Mockup A, plus the root `sharedrefs/` folder and `version.js`.
