# Mockup B.9

B.9 continues from B.7H at app v0.3.0. It keeps the established interface and adds portable ballot JSON with embedded resources, validation, import, export, and browser persistence.

Open [B.9](index.html) through HTTP or GitHub Pages. In Admin, download [SCHEMAEXAMPLE.json](SCHEMAEXAMPLE.json), import a ballot, or export current author content. Import replaces the ballot and clears practice choices.
