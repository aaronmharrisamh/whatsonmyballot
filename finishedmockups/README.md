# Finished mockups

Open [the landing page](index.html) through HTTP or GitHub Pages. [Mockup A](Mockup%20A/index.html?design=a5) opens A5 and includes A1–A5, the mobile/desktop shell, and the gallery.

Visitor choices and Admin content save separately in this browser. See the [content guide](../sharedrefs/mockup-a/CONTENT.md), [client walkthrough](../sharedrefs/mockup-a/REVIEW.md), [handoff](../sharedrefs/mockup-a/README.md), and [verification](../sharedrefs/mockup-a/VERIFICATION.md).

From the repository or extracted ZIP root, run `node preview.mjs`. The generated ZIP lives in `finishedmockups/packages/`. It includes `sharedrefs/`, `version.js`, and the public project layout; Mockup A alone is no longer a complete copy.
