From the repository root, run `node preview.mjs`. Preview and deploy the public repository files directly; there is no ZIP or package extraction step. Keep the available mockups, `sharedrefs/`, `version.js`, and root entry files together for GitHub Pages.

The local launcher follows the active line in [mockups.json](mockups.json), pinned to available B.9A. Unavailable mockups and outmoded B.8 are excluded from automatic launch.
