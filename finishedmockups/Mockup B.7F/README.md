# Mockup B.7F

Open [B.7F](index.html) through HTTP or GitHub Pages. This mockup continues directly from B.7 at app v0.2.1. B.8 remains an outmoded reference.

Empty opinion and detail controls are faded and disabled. Personal marks use an outlined oval with a smaller filled oval; the recommendation arrow or OR stays visible. The filter reads Only Recommended when on and Showing All when off. Back to Start is hidden behind a display setting.

Ballot Viewer opens at page fit with Snap off. Snap, section taps, and Next/Prev fit the selected section width. Green focus is shown only with Snap on. Unchecking Snap keeps the current view. The floating All icon fits the current page and turns Snap off.
