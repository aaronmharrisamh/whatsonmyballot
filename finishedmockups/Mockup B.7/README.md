# Mockup B.7

Open [B.7](index.html) through the project preview server or GitHub Pages.

B.7 / v0.1.8 starts with no personal choices and Only Recommendations on. Animated arrows point to empty ovals; OR sits above optional choices. Solid ovals show the reader's own choices.

Show all choices reveals one section temporarily. Both views share the main filter. Blank opinions have disabled controls; other nonrecommended opinions use a scale with an asterisk. Back and Next chips have section counts, and Back to Start preserves choices.

The viewer wheel zooms unless Snap is on, when it scrolls. Zoom stops at whole-page fit and selected-section width. Next, Prev, and Snap keep the current zoom within these bounds.

Read the [review guide](../../sharedrefs/mockup-b.7/README.md), [behavior contract](../../sharedrefs/mockup-b.7/BEHAVIOR.md), and [verification](../../sharedrefs/mockup-b.7/VERIFICATION.md). [version.js](../../version.js) supplies the app version.
