# Mockup B.5

Open [B.5](index.html) through the project preview server or GitHub Pages.

B.5 starts with a populated fictional ballot: red guide rows, faint oval checkmarks and OR marks, filled personal ovals, and sample opinions. Show opinion guide controls all guide highlights, symbols, and automatic opinion openings. Back and Next chips sit outside the readable ballot section.

Ballot Viewer has a fixed plus pattern, floating portrait paper, a vertical zoom capsule, and an optional Snap mode. Only the active section expands. A labeled edge arrow returns to an offscreen selected section.

Read the [review guide](../../sharedrefs/mockup-b.5/README.md), [demo data contract](../../sharedrefs/mockup-b.5/DATA.md), and [verification](../../sharedrefs/mockup-b.5/VERIFICATION.md). The app version comes from [version.js](../../version.js).

The fictional dataset has its own IDs and browser storage. Earlier mockups and their saves keep their existing data. The historical PDF is a layout reference; it does not contain these fictional names or sample marks. Keep the complete project layout when copying this mockup.
