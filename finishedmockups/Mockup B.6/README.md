# Mockup B.6

Open [B.6](index.html) through the project preview server or GitHub Pages.

B.6 starts with the example area and no personal choices. Its populated fictional opinion guide uses animated outlines around steady check/OR hints inside the left-hand voting ovals. A personal choice replaces the hint with a solid oval. Opinion controls use the row's color, and guide notes say Choose This or Optional.

District uses a versioned area catalog, hides dropdowns that have only one choice, and applies a selection only after Use this area. Areas without data keep Menu and Admin available. Create ballot is a placeholder.

Ballot Viewer opens at the whole-page view. Its white paper has small controls on every row and open opinions on every highlighted row. Next/Prev/Snap only pan; Zoom switches between the page and current section. The floating zoom pill, wider pan bounds, and backdrop closing make the viewer easier to explore.

Read the [review guide](../../sharedrefs/mockup-b.6/README.md), [area catalog contract](../../sharedrefs/mockup-b.6/AREAS.md), and [verification](../../sharedrefs/mockup-b.6/VERIFICATION.md). App version comes from [version.js](../../version.js). Keep the complete project layout when copying this mockup.
